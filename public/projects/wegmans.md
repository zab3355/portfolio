## Web Application Developer Co-Op — Wegmans

- **Project Links:** [wegmans.com](https://wegmans.com) | [shop.wegmans.com](https://shop.wegmans.com)
- **Agile:** Azure DevOps
- **Languages:** JavaScript, PHP, HTML, CSS, C#
- **Time Frame:** June 2019 – January 2020

---

## Overview

Part of the Wegmans Web Application Development Team. Involved within the front-end development team developing Wegmans.com pages through a custom WordPress theme using PHP and JavaScript, login functionality using Azure B2C, and working to communicate with Wegmans UX designers on the website.

At points when resources were needed, moved to the back-end development team to work on JSON databases and C# sorting algorithms for Shop.Wegmans.com. Towards the end of the project, involved within Quality Assurance for the website, mobile app, and IT Support for Wegmans Employees.

---

## The Process

Worked within an Agile environment using Microsoft Azure DevOps. Involved in daily standups, sprint cycles, corporate meetings, and discussing ideas with developers/designers from companies including Instacart, Unata, and Solu. The team heavily relied on communication using Slack and Microsoft Teams.

---

## WordPress Development

Tasked with helping the front-end development team build their custom WordPress theme using primarily PHP, JavaScript, HTML and CSS. Also required to create and use custom plugins to make Wegmans.com more efficient, while making it easy for non-technical users to create blog posts or change banners/images on the website. Also helped improve Wegmans SEO and developed off of Zeplin Prototypes from professional Wegmans UX Designers.

---

## Connections & Culture

Through working at a corporation that's so large, gained connections with other interns, Wegmans employees, Wegmans corporate higher-ups, and even designers and developers from other companies. Activities outside the office — volleyball league, going out for lunch, and getting breakfast pizza — helped build these connections further.
