## Application Development

Through developing this application we used a variety of technologies including Jenkins, OpenShift and Docker, as well as an Angular CLI frontend. The API is run using C# with SQL Queries embedded, that connects to various services allowing data to be referenced throughout Paychex applications. Also used OptaPlanner, which is a JDK AI Constraint solver that optimizes and schedules data and solves optimization issues.
